Features - Why TrustVault is Secure?

Ee page lo TrustVault yokka 4 main security features unnay. Prathi feature ni ela test cheyalo kuda rasam.

🛡️

1. IDOR Protection

Yevvaraina document ID guess chesi download cheyalani chusina, permission lekunda 403 Forbidden vastundi. Owner matrame share cheste matrame download avutundi.

Test: Viewer tho vere valla doc ID tho download try chey - 403 vastundi.

🔑

2. JWT + Revoke

Login cheste JWT token vastundi. Logout cheste aa token ni Redis lo blacklist chestham. Paatha token tho malli try cheste 401 Token revoked vastundi.

👥

3. Per-Person Sharing

"Anyone with link" kaadu. Oka specific email ki matrame share chestham - Read / Edit rights tho. Owner eppudaina revoke cheyochu.

📋

4. Immutable Audit Log

LOGIN, UPLOAD, DOWNLOAD, SHARE, READ_FAILED - anni log avutay. Audit ni evaru edit / delete cheyaleru. Admin matrame chudagaladu.
